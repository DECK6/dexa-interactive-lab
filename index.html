웹캠으로
화면을 비틀다

얼굴, 손, 몸의 윤곽을 실시간으로 추적해 화면의 규칙을 바꾸는 여덟 가지 실험. 카메라 앞에서 몸을 움직이면 렌더링이 그에 맞춰 다시 계산됩니다. 설치할 것도, 로그인할 것도 없습니다.

01

오프액시스 윈도우

OFF-AXIS WINDOW / HEAD-TRACKED PERSPECTIVE

얼굴 추적으로 머리의 3D 위치를 추정하고, 모니터를 창문처럼 다룹니다. 고개를 좌우로 움직이면 창 너머 공간이 실제 창문처럼 시차를 그리며 열립니다.

REQUIRES WEBCAM ENTER →
02

핑거 프레임

FINGER FRAME / GESTURE-MASKED SHADERS

양손 엄지와 검지로 만든 사각형 안쪽에만 이펙트가 걸립니다. 프레임을 비틀 때마다 다음 셰이더로 넘어갑니다. 손가락이 곧 뷰파인더입니다.

REQUIRES WEBCAM ENTER →
03

마리오네트

MARIONETTE / HAND-STRUNG PHYSICS PUPPET

손이 곧 마리오네트 컨트롤 바입니다. 다섯 손가락 끝에서 스트링이 내려와 로봇 퍼펫의 머리와 팔다리에 묶입니다. 기울이고 흔들어 조종해 보세요 — 손을 감추면 퍼펫이 무너집니다.

REQUIRES WEBCAM ENTER →
04

시간 메아리

TIME ECHO / SEGMENTATION TRAILS

움직이면 0.1초 전, 0.2초 전의 내가 시안에서 오렌지로 물든 잔상이 되어 따라옵니다. 멈추면 모두 내 안으로 돌아옵니다. 춤을 춰 보세요.

REQUIRES WEBCAM ENTER →
05

먼지 얼굴

DUST FACE / BLENDSHAPE PARTICLES

얼굴이 2만 개의 먼지 입자로 떠 있습니다. 입을 벌리면 얼굴이 폭발하듯 흩어지고, 다물면 다시 모여 내가 됩니다. 고개를 돌리면 바람이 붑니다.

REQUIRES WEBCAM ENTER →
06

손끝 유체

NEON FLUID / HAND-DRIVEN FLUID SIM

손가락 끝마다 네온 잉크가 흘러나와 화면 전체를 소용돌이로 채웁니다. 손가락을 집으면 잉크 한 방울이 터집니다. 진짜 유체 방정식이 돌고 있습니다.

REQUIRES WEBCAM ENTER →
07

공중 낙서

AIR GRAFFITI / PINCH-TO-DRAW LIGHT

엄지와 검지를 집으면 허공에 빛으로 글씨가 써집니다. 왼손은 시안, 오른손은 오렌지. 주먹을 쥐면 지워지고, SNAPSHOT 버튼으로 사진처럼 저장됩니다.

REQUIRES WEBCAM ENTER →
08

쌓이는 눈

SNOWFALL / MASK-COLLIDING SNOW

눈이 내 머리와 어깨, 내민 손바닥 위에 진짜처럼 쌓입니다. 몸을 털면 우수수 떨어지고, 자리를 비우면 모두 바닥으로 사라집니다.
